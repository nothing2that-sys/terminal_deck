## 이미지 설명(Alt text)

1. **Session Deck:** Terminal Deck의 실제 앱 화면. 왼쪽 세션 목록, 가운데 고정 타일 두 개와 순환 타일 두 개, 오른쪽 명령 즐겨찾기와 히스토리 패널이 보인다. 터미널에는 공개용 예시 출력이 표시되어 있다.
2. **배치 편집:** Terminal Deck의 배치 편집 화면. 4×4 논리 격자에 배치된 네 타일에 이동·크기 조절 손잡이가 나타나며, 편집 중 터미널 입력이 잠긴다는 안내가 보인다.
3. **작업 공간:** Terminal Deck의 작업 공간 선택 화면. 데모 작업 공간의 이름·설명·세션 수와 열기·수정·복제·삭제 버튼이 보인다.

## 캡처 정보

실제 0.10.1 앱 UI와 실제 PowerShell 세션을 별도 데모 데이터로 실행한 PNG입니다. 터미널 출력은 설명용 예시이며 실제 빌드·서버·Git 실행 결과가 아닙니다. 개인 작업 공간이나 실제 명령 기록은 사용하지 않았습니다. 이미지는 앱의 콘텐츠 영역을 캡처했으며 Windows 바탕화면과 다른 앱은 포함하지 않습니다.

이 파일은 게시 초안입니다. SNS에 직접 게시한 상태는 아닙니다.
